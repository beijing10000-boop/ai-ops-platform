## 生产验收

这些测试验证平台与协议行为，模型响应使用可重复的测试数据，不代表已经连接用户的生产模型、飞书租户、Zabbix 数据或 SSH 主机。模型按 Skill 作出选择仍有生成差异，应查看每次任务的真实执行记录。

升级后先验证两个连接和 Skill 工具目录，确认模板在“飞书问答 / Web 诊断 / 告警分析”需要的场景启用。未启用的场景会采用兼容流程。可用以下问题验收，将示例 IP 替换成已登记的实际地址：

1. `查询 172.20.2.101 现在 CPU 和占用最高的进程`：查看 SSH 目标与原生调用，确认没有先查 Zabbix。
2. `查询 172.20.2.101 昨天 CPU 峰值及发生时间`：查看 Zabbix 的监控项和历史/趋势调用，确认没有把当前 SSH 快照当历史证据。
3. `查询 172.20.2.101 的 /data 目录占用，展开 3 层`：按实际执行确认层数、覆盖范围和不足；为多轮扫描配置足够预算。
4. 在飞书查看同一任务的长报告，逐段核对 Web 正文；模型服务若未完整输出，应显示部分完成与原因。

Skill 不会取消服务端授权、日志读取权限或已保存预算，也不会执行任意 Shell、清理或重启。模板内五层/三十子目录是可编辑的查询指引，服务端路径、授权与只读限制继续生效。
