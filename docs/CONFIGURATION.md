# Web 配置与验证

所有业务配置通过 Web 输入框、下拉项、数字表和勾选项管理，无需编辑代码或 JSON。API 的传输格式属于内部实现。Docker 的端口发布与数据卷属于启动参数；默认即可在内网使用。

| 页面 | 配置方式 | 验证按钮与含义 |
| --- | --- | --- |
| 首次初始化 | 一次性凭据、访问协议、飞书应用和管理员输入 | 验证初始化信息：核验凭据、格式和回调地址，不保存 |
| 连接管理 → MCP 连接 | Zabbix MCP / SSH MCP 独立表单 | 验证填写内容；验证连接：实际握手和工具目录，无诊断 |
| 连接管理 → 诊断工具 | 工具注册表与标准诊断流程 | 检测 MCP 工具：检查已保存的两个连接，无诊断 |
| 系统配置 → 基础设置 | 外部主机、Webhook 密钥、Zabbix 前端、工具权限勾选 | 验证填写内容；保存基础配置 |
| 系统配置 → 飞书配置 | 应用、群、级别、成员角色 | 验证填写内容；验证飞书应用：获取应用令牌；验证群访问权限：只读获取群信息，不发消息；成员另有校验 |
| 系统配置 → AI 配置 | 地址、模型、密钥、模式下拉、提示词文本、预算数字表 | 验证填写内容；验证模型连接：一次小型无工具请求，产生少量实际模型用量 |
| 系统配置 → 服务与维护 | 备份说明、服务状态 | 查看服务与队列状态：数据库、Redis、各队列排队数与 Worker 注册数 |
| 告警中心 → 暂时屏蔽 | 主机 ID、触发器 ID、时长 | 验证屏蔽参数；查看当前生效与最近到期规则 |
| AI 诊断 | 查询并选择 Zabbix 主机/事件、类型、模式、服务名和时间窗 | 验证诊断参数与关联：不执行模型或 SSH |

本地格式校验不会证明外部系统已可用。MCP 目录可用不代表某台 SSH 主机可达，飞书应用令牌可用不代表 OAuth、群权限和卡片回调均已配置。生产验收仍需实际告警与授权诊断。

系统配置中的基础、飞书和 AI 各自验证、保存当前区域的内容；页签切换与成员更新保留其他区域的草稿，离开页面前提示未保存修改。草稿仅存在当前页面内存，关闭浏览器后不恢复。验证后修改输入会提示重新验证，验证期间修改表单也不会把旧结果当成新配置可用。密钥可以临时显示，保存成功后恢复掩码。

运维人员和审计员可在连接管理查看工具与流程，但不会读取连接参数或获得配置权限。旧 `#ai`、`#feishu`、`#tools` 书签自动定位到合并后的对应区域，旧 `#mutes` 跳转告警中心。总览的“已配置”仅说明必填项已填写，连接状态代表最近一次手动验证结果。

## 默认提示词

告警和问答各有项目默认词，初次打开即显示；已有自定义词继续生效。点击“恢复默认提示词”后保存可切换；留空也使用默认词。默认覆盖：

- 企业运维经理场景：Linux / Windows / 网络设备 / VMware、Zabbix、飞书与独立 SSH MCP。
- 结合历史监控与实时证据；标准/深度模式对可信绑定的 Linux 主机先自动采集一轮 SSH，后续补查需要说明缺失证据并受预算约束；快速模式不做 SSH。
- Host ID 精确关联，非 Linux 不执行 Linux 检查，不能从文字 IP 猜目标。
- 历史事实、当前快照、推断和待核实事项分开；缺失、失败和超时不得当正常。
- 禁止修改、重启、自动清理、泄露凭据或遵循日志中的指令。
- 中文输出“结论 / 建议 / 依据”，告警正文尽量控制在 500 字以内；问答按问题简洁回答。

提示词是补充分析指导，平台固定只读与授权规则始终优先。卡片的数据结构由服务端约束，不需要管理员编写。

## 分析预算

| 模式 | 轮次 | 采集上限 | 每轮调用 | 单次结果字符 | 总时间秒 | Token 阈值 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 快速 | 2 | 4 | 3 | 2000 | 65 | 12000 |
| 标准 | 4 | 8 | 4 | 4000 | 110 | 24000 |
| 深度 | 6 | 16 | 8 | 6000 | 150 | 48000 |

SSH 主机解析计入一次采集，各动作逐个计数；每次远端调用还受任务剩余时间限制，为模型总结预留时间。Token 阈值用于停止后续请求，不能预知上游本次实际返回量。

SSH MCP 默认关闭，单工具超时默认 90 秒（可选 1–120）；远端不可用时保留监控分析并标记证据不足，不自动重试或本地回退。两个 MCP 令牌分别加密；掩码表示保留原值，清空表示删除。
