# Web 配置与验证

所有业务配置通过 Web 输入框、下拉项、数字表和勾选项管理，无需编辑代码或 JSON。API 的传输格式属于内部实现。Docker 的端口发布与数据卷属于启动参数；默认即可在内网使用。

| 页面 | 配置方式 | 验证按钮与含义 |
| --- | --- | --- |
| 首次初始化 | 一次性凭据、访问协议、飞书应用和管理员输入 | 验证初始化信息：核验凭据、格式和回调地址，不保存 |
| 连接管理 → MCP 连接 | Zabbix MCP / SSH MCP / 日志 MCP 独立表单 | 验证填写内容；验证连接：实际握手和工具目录（日志 MCP 列出本令牌获授权的日志工具），无诊断 |
| 连接管理 → 诊断工具 | 工具注册表与诊断类型 | 检测 MCP 工具：检查已保存的两个连接，无诊断 |
| 系统配置 → 基础设置 | 外部主机、Webhook 密钥、Zabbix 前端、工具权限勾选 | 验证填写内容；保存基础配置 |
| 系统配置 → 飞书配置 | 应用、群、级别、成员角色 | 验证填写内容；验证飞书应用：获取应用令牌；验证群访问权限：只读获取群信息，不发消息；成员另有校验 |
| 系统配置 → AI 配置 | 地址、模型、密钥、单次请求超时、深度思考、默认模式下拉、明细保留天数、预算数字表 | 验证填写内容；验证模型连接：一次小型无工具请求，产生少量实际模型用量 |
| 系统配置 → 服务与维护 | 备份说明、服务状态 | 查看服务与队列状态：数据库、Redis、各队列排队数与 Worker 注册数 |
| 告警中心 → 暂时屏蔽 | 主机 ID、触发器 ID、时长 | 验证屏蔽参数；查看当前生效与最近到期规则 |
| AI 诊断 | 查询并选择 Zabbix 主机/事件、类型、模式、服务名和时间窗 | 验证诊断参数与关联：不执行模型或 SSH |

本地格式校验不会证明外部系统已可用。MCP 目录可用不代表某台 SSH 主机可达，飞书应用令牌可用不代表 OAuth、群权限和卡片回调均已配置。生产验收仍需实际告警与授权诊断。

系统配置中的基础、飞书和 AI 各自验证、保存当前区域的内容；页签切换与成员更新保留其他区域的草稿，离开页面前提示未保存修改。草稿仅存在当前页面内存，关闭浏览器后不恢复。验证后修改输入会提示重新验证，验证期间修改表单也不会把旧结果当成新配置可用。密钥可以临时显示，保存成功后恢复掩码。

运维人员和审计员可在连接管理查看工具与流程，但不会读取连接参数或获得配置权限。旧 `#ai`、`#feishu`、`#tools` 书签自动定位到合并后的对应区域，旧 `#mutes` 跳转告警中心。总览的“已配置”仅说明必填项已填写，连接状态代表最近一次手动验证结果。

## 诊断规则

诊断指引与报告要求统一由 Skill 管理（见 [SKILLS.md](SKILLS.md)），AI 配置不再提供告警/问答提示词。升级前保存的旧提示词记录保留在数据库中供回滚，但不参与新分析。平台固定的只读与授权规则始终优先；卡片的数据结构由服务端约束，不需要管理员编写。

## 分析预算

| 模式 | 轮次 | 采集上限 | 每轮调用 | 单次结果字符 | 总时间秒 | Token 阈值 | 保底补查次数 | 追加轮次 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 快速 | 3 | 8 | 4 | 2500 | 90 | 16000 | 3 | 0 |
| 标准 | 5 | 16 | 6 | 4000 | 180 | 32000 | 5 | 1 |
| 深度 | 8 | 24 | 8 | 6000 | 300 | 64000 | 8 | 2 |

SSH 主机解析与各动作逐个计入采集次数（工具参数结构查询不计）；每次远端调用还受任务剩余时间限制，为模型总结预留时间。Token 阈值用于停止后续请求，不能预知上游本次实际返回量。

位置：**系统配置 → AI 配置 → 分析预算**，修改对应模式的数字后保存 AI 配置。已有自定义配置不会自动覆盖，未填写的项使用上表默认值；改动仅影响新任务或点击重试创建的新任务。报告的“分析预算”显示创建任务时保存的上限、实际消耗和停止原因，可直接跳转到配置页。这里的预算限制采集次数、模型轮次、时间及 Token，不是账户余额或金额。

后两列（`follow_up_calls`、`extension_rounds`）不在 Web 预算表中显示，按默认值执行。预采集计入采集次数，但模型始终保留“保底补查次数”（不超过采集上限）；存在采集失败项且时间允许时，可再追加最多“追加轮次”轮。低上限可能使部分历史无法补查，报告会明确列出。没有执行的动作不伪装成远端失败，也不增加采集计数；目录展开的每个根路径扫描各消耗一次采集。

SSH MCP 默认关闭，单工具超时默认 90 秒（可选 1–120）；远端不可用时保留监控分析并标记证据不足，不本地回退。三个 MCP 令牌分别加密；掩码表示保留原值，清空表示删除。

日志 MCP（日志分析平台）只需地址与令牌：地址形如 `http://日志平台IP:7077/mcp`，令牌在日志平台“MCP 接入”签发（`logmcp_` 开头，只显示一次）。两项须同时填写，都留空表示不接入；不接入或连接失败时报告只在“能力说明”中注明，不算诊断不足。单次日志工具调用最长 30 秒。令牌可在日志平台限定工具、日志类型与来源分组，平台按 `log_list_tool_catalog` 只向模型展示获授权的工具；修改授权后在“诊断工具”点“刷新目录”或重新验证连接，各 Worker 的工具目录缓存随即失效。

除追加轮次（0–4）外，预算项不设代码上限，仍校验整数与最小值；16 轮、每轮 16 次、16000 字符、1200 秒或 160000 Token 等均可在 Web 保存。任务按填写的预算停止，0 不表示无限制。RQ 不用固定时长提前终止任务，失联任务清理也按创建时保存的时间预算加宽限时间判断。单次 MCP/模型调用仍有各自超时，远端权限和查询范围约束继续生效。
