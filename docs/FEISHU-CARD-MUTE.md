# 飞书卡片与本地屏蔽

企业应用启用 `card.action.trigger` 长连接回调并发布，平台接收器与消息事件共用一个 App ID。配置步骤见 FEISHU.md。

- super_admin / ops_admin 可屏蔽同一 host_id + trigger_id，时长 1、4、24、72、168 小时。
- 操作值带签名并重新检查权限；分析操作还验证消息/事件/群关联。主密钥与各进程一致，迁移后旧签名需用新卡片复测。
- 只过滤本平台后续问题通知，不调用 Zabbix 写 API，不修改维护周期；已通知问题的恢复关联继续工作。
- Web 系统配置中的飞书告警屏蔽可查看生效记录、手动登记屏蔽与提前解除，卡片也可解除。

真实租户验收：专用触发器产生问题 → 管理员选 1 小时 → 确认记录 → 同类新问题被过滤 → 其他触发器及恢复不受影响 → 提前解除 → 再次产生问题。另以未授权成员验证拒绝。不要用生产重大事件做故障注入。
